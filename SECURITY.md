# Security policy

Orchestra is pre-release and currently contains scaffold code only. No deployed product version is supported yet. Supported-version policy, private vulnerability intake, response targets and coordinated disclosure procedures must be established in M0-08 before external use.

Do not include credentials, account tokens, private repositories or live provider transcripts in public issues. Check this repository's GitHub Security tab for private vulnerability reporting; its enablement has not been verified by the scaffold task. If unavailable, obtain a private channel from the owner before sending sensitive details.

Architecture rules are enforced locally. The custom vendor-endpoint and PTY-parsing compliance rules are scheduled for M0-08 and are not implemented by the reserved ESLint namespace.
